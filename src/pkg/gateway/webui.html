    In-browser worker
    
      
    
        
    
          Run a relay worker in this browser tab. Clicking Connect dynamically loads
          @mlc-ai/web-llm from esm.run and downloads the
          selected model's weights on first use -- nothing third-party is fetched until
          you click. The module runs in an opaque-origin sandboxed iframe
          (no access to this page's localStorage, no /v1/* credentials), and
          it talks to the gateway with a relay-scoped token that unlocks
          only /v1/relay/* -- so a compromised model can't impersonate you
          against the rest of PasClaw. Closing the tab disconnects.
