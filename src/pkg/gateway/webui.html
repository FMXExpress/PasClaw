      Security and tool calls

      The model runs in a dedicated Web Worker, which has no window or localStorage, so it can't read this page's stored gateway token. It talks to the gateway with the relay-scoped token, which unlocks only /v1/relay/*, so a compromised model can't act as you.

      Tool calls: WebLLM takes the tools argument only for the Hermes 2 Pro and Hermes 3 models marked "tool-calls supported". Other models still answer text-only turns; when a turn carries tools, the worker drops them and asks again, so the reply comes back as text with no structured tool_calls.

      WebGPU isn't available in this browser, so it can't run a model here. Use or on a machine with a GPU instead.
