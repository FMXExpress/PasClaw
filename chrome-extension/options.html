PasClaw for Chrome

Connects to a running pasclaw gateway (or pasclaw serve, or the Docker image).

Loopback addresses work out of the box. Chrome asks once for access to any other host.

Needed when the gateway sets PASCLAW_GATEWAY_TOKEN / gateway.token, and recommended for any gateway that is not on this machine. Stored in this browser profile only.

How much of a page is attached when Page is on. Long pages cost tokens on every turn.
